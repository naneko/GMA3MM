## Troubleshooting

### OSC client not connecting to GMA3
- Check GMA3 in/out network interface is set to a loopback or localhost/127.0.0.1
- [Windows Only] Set up a loopback interface
- Ensure GMA3 is connected to a session and not running in standalone mode in the Network settings
